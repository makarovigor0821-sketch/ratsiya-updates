# Рация — канал обновлений

Этот публичный репозиторий содержит только опубликованные APK-обновления приложения «Рация», контрольные суммы и номера версий.

Исходный код приложения хранится в отдельном закрытом репозитории.

## Для приложения
Приложение проверяет последний GitHub Release и предлагает скачать обновление. Android может потребовать подтвердить установку.

Не загружайте сюда пароли, токены или ключи подписи.
